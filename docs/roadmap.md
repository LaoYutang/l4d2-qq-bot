## 已实现

- Python 3.12+、asyncio、aiohttp、python-a2s、Pillow；独立于 AstrBot。
- QQ Token、WebSocket 状态机、心跳、恢复、重连；全量群消息与 @ 事件、去重及有界 worker 队列。
- 真实单服 / 临时 connect / 综合查询、原生 Markdown 与动态连接按钮、可选 PNG。
- 地图名称 API、1 小时成功缓存、并发合并；所有查询入口使用同一逻辑。
- 黑盒语音实时人数、成员名单、10 分钟昵称缓存。
- Steam 工坊单品 / 合集与原版解析协议；原版结果正文。
- Source RCON / 重启、管理员权限、精确匹配、30 秒确认、审计与禁止自动重放。
- QQ 闪传的选服、选文件 / 多选 / 全部、面板解析和下载任务提交；会话隔离、超时和文件白名单。
- 独立配置页：原版增删 / 排序、密码显隐、业务参数、原子保存、覆盖冲突检测和即时生效。
- 环境变量配置的页面密码，localStorage 与原始密码请求头鉴权，无 JWT；QQ ID / 密钥保持环境变量注入。
- 获取群 ID / 用户 ID；没有群配置也可启动并取得群 OpenID。
- Docker 非 root、可写配置卷、只读根目录、中文字体；PR / 分支检查与 tag 发布流程。
