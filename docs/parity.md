## 有意保留的差异

- 使用 QQ 官方协议和原生 Markdown / keyboard，移除 AstrBot 生命周期及插件 Page Bridge；单服按钮随本次结果构造。
- 不发送“正在查询 / 解析”等待消息，不加入产品说明、快捷名说明、脱敏说明或统计页脚。正常结果文本采用原版文案；平台拒绝或接口失败才显示必要错误。
- 原版把 PLAYER 失败显示成无人；新版保留未知状态，避免误报。语音名单沿用统一脱敏设置。
- 临时 connect 默认限制公网；群配置中的可信服务器允许私网。
- RCON / 重启增加成员隔离的明确确认。文件选择提示即为闪传下载确认；配置保存会取消待确认会话。
- 工坊默认 Steam 官方接口，原第三方接口可配置。缺下载地址 / 私有条目如实显示，不生成下载链接。合集取数有上限，过长回复按 QQ 配额拆分，单项可用页码查看。
- 界面中的群、管理员均使用官方 OpenID，普通群号 / QQ 号不能直接迁移。

## 验证边界

本次使用本地 HTTP、WebSocket、UDP、TCP 模拟服务验证，另用 Chromium 操作独立配置页。Docker 镜像已构建，容器完成非 root / 只读根目录运行、环境密码与请求头鉴权、数据卷保存和重启保留验收。没有使用真实 QQ / 黑盒 / 游戏服务器管理凭据，没有向真实服务器发送 RCON、重启或下载任务。新管理功能和地图 API / 黑盒实际凭据仍需部署后联调；原有 QQ 卡片与按钮的历史群测记录继续保留。

旧 AstrBot 配置的普通群号、QQ 号需要人工映射为 OpenID，暂未提供自动导入器。高级刷新 / 翻页按钮也仍在后续规划；它们不是原版 main.py 中缺失迁移的功能。
